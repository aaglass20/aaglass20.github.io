# Drill Candidates Index

Drill ideas to research and write up, per sport. Claude works down this list when
gathering, and adds new names found along the way. Rules: `RULES.md`.

**Status:** ✅ written (in `data/<sport>.js`) · ⬜ to research · ❌ skipped (reason)

Before adding a drill: search this file and the data file for the name **and** its
alternate names — many drills go by several names.
