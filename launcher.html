🛠️ Repo Launcher

Quick reference for running local tools and scripts

Run everything from the terminal menu: bash ~/git/aaglass20.github.io/run.sh
Available Tools
🎬
Video Downloader
Web UI Auto-install
Downloads videos from any yt-dlp-supported site (YouTube, Twitter/X, etc.). Starts a local server and opens a browser UI. Files land in video-downloader/downloads/.
Terminal
bash ~/git/aaglass20.github.io/video-downloader/start.sh
Open UI (localhost:8765) — server must be running
📹
Add Videos to BDU
Interactive BDU
Scans BDU/vid/ for new untracked .mp4 files and adds them to the best-matching HTML drill page. Prompts for title, summary, and target page. Use --auto to skip prompts.
Terminal — interactive
cd ~/git/aaglass20.github.io/BDU && zsh add-videos.sh
Terminal — auto mode
cd ~/git/aaglass20.github.io/BDU && zsh add-videos.sh --auto
🔄
Update BDU Search Index
One-shot BDU
Regenerates BDU/search-index.json by crawling all BDU HTML pages. Run this after adding or editing any BDU drill pages. Shows a git diff of changed files on completion.
Terminal
bash ~/git/aaglass20.github.io/BDU/UPDATE-INDEX.sh
