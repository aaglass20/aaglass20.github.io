1-2 & Overlap Pattern — Live Animation

A→B one-two, then A lays off to C overlapping. Combination play made automatic.

Key Coaching Points

  • Pass and move — A does not stop after passing to B
  • B one touch lay-back into A's run — weight it, don't shoot it
  • C's overlap run must be timed to arrive as A lays off — not early
  • Call 'OVER' early so C knows the run is on
  • Rotate every rep: A→B→C→back of line
